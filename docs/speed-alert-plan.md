# 速度表示・制限速度アラート 企画メモ（実装前）

> ステータス: 企画段階。まだ実装しない。

## 1. 目的

運転中に「今の速度」と「今走っている道の制限速度」をひと目で確認でき、
制限速度を超えたら（設定に応じて）アラートを出す。

- まずは **ブラウザで開くWebアプリ** として作る
- 将来 **スマホアプリ化** もできる構成にしておく

## 2. 機能一覧

### 2-1. 無料で提供する基本機能（MVP）

| 機能 | 内容 |
|---|---|
| 現在速度の表示 | GPSから取得した速度を km/h で大きく表示 |
| 制限速度の表示 | 現在地の道路の制限速度を標識風に表示。不明な場合は「不明」または「法定速度（推定）」と明示 |
| 超過アラート | 制限速度を超えたら通知。下の設定で ON/OFF と条件を変えられる |
| 画面スリープ防止 | 表示中は画面が消えないようにする |

### 2-2. アラート設定

- アラート ON / OFF
- 許容幅: 制限速度 +0 / +5 / +10 km/h など（何km/h超えたら鳴らすか）
- 通知方法: 音 / 音声読み上げ（「制限速度を超えています」）/ 画面の色を変える / バイブ
- 連続で鳴り続けないよう、一度鳴ったら一定時間（例: 10秒）は鳴らさない
- 制限速度が「不明」の道ではアラートを出すか出さないか

### 2-3. 将来の有料機能

- **ネズミ捕り（速度取締り）報告**: ユーザーが取締り場所を報告し、他のユーザーの地図・画面に表示する。近づいたら通知
- 課金ルール（案）
  - 有料プラン: **月額 180円**
  - ネズミ捕りを報告すると **1週間無料**

## 3. 技術的な実現方法

### 3-1. 現在速度（GPS）

- ブラウザの位置情報API（Geolocation API の `watchPosition`）で取得できる
- 端末によっては速度の値が入ってこないことがあるため、
  その場合は「前回の位置からの距離 ÷ 経過時間」で計算して補う
- **HTTPS で公開する必要がある**（HTTPでは位置情報が使えない）
- トンネル内や高架下ではGPSが途切れるので「測位中…」表示が必要

### 3-2. 制限速度

一番難しい部分。データの入手先の候補：

| データ元 | 費用 | 日本での精度 | 備考 |
|---|---|---|---|
| OpenStreetMap（Overpass API） | 無料 | 道によってばらつきが大きい。登録されていない道も多い | MVP向き。表示にクレジット記載が必要 |
| HERE / TomTom の地図API | 従量課金（無料枠あり） | 比較的良い | 本格運用向き |
| Google Roads API | 有料 | 良い | 制限速度の取得は契約条件あり。要確認 |
| 国内地図会社（ゼンリン等） | 要見積 | 最も良い | 法人契約が前提 |

- **方針案**: MVPは OpenStreetMap を使い、データが無い道は
  法定速度（一般道 60km/h、高速道路 100km/h）を「推定」として表示する
- 並行する道路・高架・側道では「どの道を走っているか」の判定を間違えやすい。
  進行方向も使って判定する

### 3-3. ブラウザ版の制約（アプリ化を検討する理由）

| 項目 | ブラウザ版 | スマホアプリ版 |
|---|---|---|
| 画面を開いている間の速度表示・アラート | ○ | ○ |
| 画面を閉じた/他アプリ使用中のアラート | **×（動かない）** | ○ |
| iPhoneでのバイブ | × | ○ |
| 音声アラート | 最初に画面を1回タップする必要あり | ○ |
| 配布 | URLを開くだけ | ストア審査が必要 |

- ブラウザ版は **PWA**（ホーム画面に追加できるWebアプリ）として作る
- 後で Capacitor 等でそのままスマホアプリに包めるよう、画面とロジックを分けて作る
- カーナビや地図アプリと同時に使いたい場合は、アプリ版が必要になる

## 4. ネズミ捕り報告の設計メモ

- 報告内容: 場所（現在地）、種類（ネズミ捕り / 検問 / 白バイ・パトカー 等）、時刻
- 取締りは一時的なので、**数時間で自動的に消える** ようにする
- 他のユーザーが「まだいた / もういない」を押せるようにして精度を上げる
- 運転中の操作は危険（ながら運転）なので、
  **停車中（速度0付近）のみ報告できる** / ボタン1つで報告できる、などの配慮が必要
- 報告にはアカウント（ログイン）が必要

## 5. 課金まわりの注意点

### 5-1. 「報告で1週間無料」の悪用対策

そのままだと、嘘の報告を繰り返せば永久に無料で使えてしまう。対策案：

- 他のユーザーから「確認した」が付いた報告だけを無料特典の対象にする
- 特典は **1ヶ月に最大◯回** までにする
- 同じ場所・短時間での連続報告は1回扱い
- 明らかに走行していない位置からの報告は無効

### 5-2. 決済手段と手数料

| 提供形態 | 決済 | 180円のうち手元に残る目安 |
|---|---|---|
| ブラウザ版 | Stripe などのカード決済 | 約173円（手数料 約3.6%） |
| iPhone / Android アプリ版 | ストアのアプリ内課金が原則必須 | 約126〜153円（手数料 15〜30%） |

- 月額180円は手数料の影響が大きいので、アプリ版の価格は別途検討

### 5-3. 必要な書類・表示

- 特定商取引法に基づく表記（有料化する場合は必須）
- プライバシーポリシー（位置情報を扱うため）
- 利用規約・免責事項（「表示される制限速度は参考情報。実際の標識に従ってください」など）

## 6. 安全面の配慮

- 表示は大きく、文字は最小限。運転中に操作しなくて済む設計にする
- 起動時に「運転中は操作しないでください」と表示
- 制限速度の表示ミスで違反になっても責任を負わない旨を免責事項に明記

## 7. 進め方（案）

1. **試作**: 現在速度の表示だけのWebページを作り、実際に車で精度を確認
2. **MVP**: OpenStreetMap で制限速度を表示 + 超過アラート + 設定画面（PWA）
3. **検証**: 自分の生活圏で制限速度データがどれくらい正しいか確認し、有料地図APIが必要か判断
4. **アカウント・報告機能**: ログイン、ネズミ捕り報告と表示
5. **課金**: 月額180円 + 報告特典
6. **アプリ化**: バックグラウンドでのアラートが必要ならスマホアプリ版を作る
