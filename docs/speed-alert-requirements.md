# 要件定義書：速度表示・制限速度アラート（仮称「スピードガイド」）

| 項目 | 内容 |
|---|---|
| 版 | 1.0 |
| 作成日 | 2026-09-23 |
| 状態 | 要件定義（実装前） |
| 開発場所 | 自分のPC（ローカル開発。GitHubは使わない） |

---

## 1. 概要

### 1-1. 目的
運転中に「現在の速度」と「今走っている道路の制限速度」を一目で確認できるようにし、
制限速度を超えたときに設定に応じて警告する。
将来は、ユーザー同士で速度取締り（ネズミ捕り）の場所を共有する有料機能で収益化する。

### 1-2. 提供形態
- 第1段階: **ブラウザで開くWebアプリ（PWA）**。スマホのホーム画面に追加して使える
- 第2段階以降: 必要になったら同じコードを **スマホアプリ（iPhone / Android）** に変換する

### 1-3. 対象エリア
- 日本国内。**福井県とその周辺から開始**し、段階的に広げる

### 1-4. 用語

| 用語 | 意味 |
|---|---|
| PWA | ホーム画面に追加でき、アプリのように使えるWebページ |
| 制限速度（指定） | 標識などで決められた最高速度。地図データから取得する |
| 法定速度（推定） | 標識がない場合の速度（一般道60km/h、高速道路100km/h）。データが無いときの代わりに使う |
| 取締りスポット | 近い場所で出た取締り報告をまとめた1つの地点 |
| 有料会員 | 月額180円を払っている人、または報告特典で無料期間中の人 |

## 3. 機能要件

優先度: **必須** = そのフェーズで必ず作る ／ **推奨** = できれば作る

### 3-1. 現在速度（P0）

| ID | 要件 | 優先度 |
|---|---|---|
| F-101 | GPSから現在速度を取得し、km/h の整数で大きく表示する | 必須 |
| F-102 | 1秒程度ごとに更新する | 必須 |
| F-103 | 端末が速度を返さない場合は「前回位置からの距離 ÷ 経過時間」で計算する | 必須 |
| F-104 | 値のブレを抑えるため、直近数秒の平均で表示する。5km/h未満は0と表示 | 必須 |
| F-105 | 位置の誤差が大きい（50m超）ときは、その値を使わない | 必須 |
| F-106 | GPSが取れないときは「測位中…」を表示し、最後の値を薄く表示する | 必須 |
| F-107 | 位置情報の利用が許可されていないときは、許可の手順を案内する | 必須 |

### 3-2. 制限速度（P1）

| ID | 要件 | 優先度 |
|---|---|---|
| F-201 | 現在地付近の道路の制限速度を OpenStreetMap から取得して標識風に表示する | 必須 |
| F-202 | 現在地から25m以内の道路のうち、**進行方向と向きが近い道路**を「走っている道」と判断する | 必須 |
| F-203 | 制限速度のデータが無い道路は、法定速度を「推定」と分かる見た目で表示する（高速道路100、それ以外60） | 必須 |
| F-204 | 道路が判断できないときは「不明」と表示する | 必須 |
| F-205 | 表示がパタパタ切り替わらないよう、別の道路と判断した状態が数秒続いてから切り替える | 必須 |
| F-206 | 道路データは周辺（約1km四方）をまとめて取得して端末に保存し、通信量と問い合わせ回数を減らす | 必須 |
| F-207 | 通信が切れても、保存済みの範囲では制限速度を表示し続ける | 推奨 |
| F-208 | 「この制限速度は間違っている」とユーザーが報告できる | 推奨（P2） |

### 3-3. 超過アラート（P1）

| ID | 要件 | 優先度 |
|---|---|---|
| F-301 | 現在速度が「制限速度 + 許容幅」を **3秒以上** 超えたらアラートを出す | 必須 |
| F-302 | アラート中は速度表示を赤くする | 必須 |
| F-303 | 音または音声（「制限速度を超えています」）で知らせる | 必須 |
| F-304 | 一度鳴ったら、速度が下がるまでは再度鳴らさない。下がらなくても最短30秒は間隔をあける | 必須 |
| F-305 | 制限速度が「推定」「不明」の道路では、初期設定ではアラートを出さない | 必須 |
| F-306 | 端末が対応していればバイブも使う（Androidのみ） | 推奨 |

### 3-4. 設定（P1）

設定は端末内に保存する（P2以降はアカウントにも保存）。

| 設定項目 | 選択肢 | 初期値 |
|---|---|---|
| アラート | ON / OFF | ON |
| 許容幅 | +0 / +5 / +10 / +15 km/h | +10 |
| 通知方法 | 音 / 音声 / 画面の色のみ | 音声 |
| 音量 | 5段階 | 3 |
| 推定・不明の道路でもアラート | ON / OFF | OFF |
| 画面の明るさ固定（スリープ防止） | ON / OFF | ON |
| 表示テーマ | 自動 / 昼 / 夜 | 自動 |

### 3-5. 取締り報告（P2）

| ID | 要件 | 優先度 |
|---|---|---|
| F-501 | ログインしているユーザーは取締りを報告できる（無料ユーザーも可） | 必須 |
| F-502 | 報告の種類: ネズミ捕り（定置式）／移動式オービス／検問／パトカー・白バイ | 必須 |
| F-503 | **運転中は報告できない**。速度10km/h以下の停車中のみ報告ボタンを押せる | 必須 |
| F-504 | 停車後に報告するため、「1分前 / 3分前 / 5分前に通った場所」から地点を選べる（走行履歴は端末内に直近10分だけ保持） | 必須 |
| F-505 | 報告時刻・地点・進行方向・種類をサーバーに送る | 必須 |
| F-506 | 報告の受付範囲は当面「福井県と周辺」に限定する | 必須 |
| F-507 | 同じ人が同じスポットに報告できるのは1日1回まで | 必須 |
| F-508 | 報告を見た人が「いた／いなかった」を押せる | 推奨 |

### 3-6. 取締りスポットの集計（P2）

| ID | 要件 |
|---|---|
| F-601 | 半径200m以内・同じ道路・進行方向の差が45度以内の報告を、1つの **取締りスポット** にまとめる |
| F-602 | スポットごとに累計報告件数と最終報告日時を記録する |
| F-603 | 表示の基準は **「累計報告100件以上」**。ただしこの数値は管理者が変更できる設定値とする |
| F-604 | **サービス開始時の基準は10件**とし、利用者が増えたら段階的に100件へ引き上げる（開始直後は100件に届く場所がなく、有料会員が何も見られないため） |
| F-605 | 基準とは別に、**直近3時間以内に2人以上から報告**がある地点を「速報」として表示する |

### 3-7. 取締り情報の表示（P2：有料会員のみ）

| ID | 要件 |
|---|---|
| F-701 | 有料会員には、進行方向の前方1km以内にあるスポットを速度画面に表示する（距離と種類） |
| F-702 | スポットの500m手前で音声で知らせる（「この先500m、取締り多発地点です」） |
| F-703 | 無料ユーザーには取締り情報を表示しない。設定画面で「有料プランで見られるようになります」と案内する |
| F-704 | 地図での一覧表示はP4で対応する |

### 3-8. アカウント（P2）

| ID | 要件 |
|---|---|
| F-801 | メールアドレス（ログイン用リンク送信）または Google アカウントでログインできる |
| F-802 | 速度表示・制限速度・アラートはログインしなくても使える |
| F-803 | 退会でき、退会時は報告以外の個人データを削除する（報告は誰のものか分からない形で残す） |

### 3-9. 課金（P3）

| ID | 要件 |
|---|---|
| F-901 | 有料プラン: **月額180円（税込）**、自動更新、いつでも解約可能 |
| F-902 | 有料プランの特典: 取締り情報の表示（3-7） |
| F-903 | Webでの決済は Stripe を使う（クレジットカード） |
| F-904 | 解約しても、支払い済みの期間の終わりまでは使える |

### 3-10. 報告特典（P3）

| ID | 要件 |
|---|---|
| F-1001 | 報告すると **7日間の無料期間** がもらえる（取締り情報が見られる） |
| F-1002 | 特典の対象は「**24時間以内に他の人からも同じスポットへの報告、または『いた』がついた報告**」のみ（嘘の報告を防ぐため） |
| F-1003 | 特典がもらえるのは **7日間に1回まで**。無料期間の残りは最大14日まで貯められる |
| F-1004 | 有料会員が特典をもらった場合は、次回の支払日を7日延ばす |
| F-1005 | 特典を受け取ったときはアプリ内で通知する |

## 4. 画面要件

地図は使わない。運転中に見るので **文字は大きく、情報は最小限** にする。

### 4-1. 画面一覧

| 画面 | 内容 | フェーズ |
|---|---|---|
| 初回説明 | 使い方、位置情報の許可、「運転中は操作しないで」の注意、免責事項への同意 | P1 |
| メイン（速度画面） | 下図 | P0〜 |
| 設定 | 3-4 の項目 | P1 |
| 報告 | 種類と地点（1/3/5分前）を選ぶだけ | P2 |
| ログイン / アカウント | ログイン、有料プラン加入・解約、無料期間の残り日数 | P2〜P3 |
| 規約類 | 利用規約、プライバシーポリシー、特定商取引法に基づく表記 | P3 |

### 4-2. メイン画面のレイアウト（縦持ち）

```
┌──────────────────────┐
│ ⚙            GPS ●    │  ← 設定ボタン / GPS状態
│                        │
│         58             │  ← 現在速度（画面の半分近い大きさ）
│        km/h            │
│                        │
│        ( 50 )          │  ← 制限速度（標識風の丸）
│                        │     推定のときは点線の丸＋「推定」
│ ⚠ この先 800m          │  ← 取締りスポット（有料会員のみ）
│   取締り多発地点        │
│                        │
│   [ 報告 ]             │  ← 停車中のみ押せる
└──────────────────────┘
```

- 横持ちでは速度と制限速度を左右に並べる
- 夜間は黒背景の暗い配色（まぶしさ防止）
- 超過中は速度の数字と背景が赤になる

## 5. 非機能要件

| 分類 | 要件 |
|---|---|
| 対応端末 | iPhone（iOS 17以降の Safari）、Android（Chrome 最新版）。PCのブラウザは開発・確認用 |
| 表示速度 | 起動から速度表示まで3秒以内（GPS取得時間を除く） |
| 更新間隔 | 速度: 約1秒ごと。制限速度: 道路が変わってから3秒以内に反映 |
| 電池 | 1時間使って電池消費15%以内を目安 |
| 通信量 | 1時間あたり5MB以内を目安（道路データを保存して再利用する） |
| 通信 | HTTPSが必須（位置情報を使うため） |
| オフライン | 通信が切れても速度表示は続ける |
| プライバシー | 走行履歴は端末内に直近10分だけ保持し、サーバーに送らない。サーバーに送るのは報告地点のみ |
| セキュリティ | 決済情報は Stripe が管理し、自分のサーバーには保存しない |
| 利用規約の遵守 | OpenStreetMap の出典表示「© OpenStreetMap contributors」を画面に出す。Overpass API へ短時間に大量の問い合わせをしない |

### ブラウザ版の制約（受け入れる）
- 画面を閉じたり、他のアプリ（カーナビ等）を使っている間はアラートが動かない
- iPhone ではバイブが使えない
- 音声アラートを鳴らすには、起動後に1回画面をタップしてもらう必要がある

→ これが問題になったらP4でスマホアプリ化する。

## 6. データ要件（P2以降、サーバー側）

| データ | 主な項目 |
|---|---|
| ユーザー | ID、メール、登録日、有料状態、有料期限、特典の無料期限 |
| 報告 | ID、ユーザーID、地点（緯度経度）、進行方向、種類、報告日時、特典対象か |
| 取締りスポット | ID、中心地点、道路ID、進行方向、種類、累計報告件数、最終報告日時 |
| 確認（いた/いなかった） | ID、ユーザーID、スポットID、結果、日時 |

端末内に保存するもの: 設定、道路データのキャッシュ、直近10分の走行履歴。

## 8. 課金・法務・安全

### 8-1. 収益の目安
| 形態 | 手元に残る額（180円あたり） |
|---|---|
| Webブラウザ版（Stripe） | 約173円 |
| スマホアプリ版（ストア課金） | 約126〜153円 |

スマホアプリ化するときは、アプリ内の課金をストアの仕組みで行う必要がある。

### 8-2. 必要な書類（P3までに用意）
- 利用規約
- プライバシーポリシー（位置情報の扱いを明記）
- 特定商取引法に基づく表記（個人の場合、住所・電話番号は「請求があれば遅滞なく開示」とする方法がある）

### 8-3. 免責事項（初回起動時に同意）
- 表示される制限速度は参考情報であり、実際の標識・標示に従うこと
- 取締り情報はユーザーの報告であり、正確さを保証しない
- 本アプリの表示により生じた違反・事故について責任を負わない

### 8-4. 安全への配慮
- 運転中に操作が必要な機能を作らない（報告は停車中のみ）
- 初回起動時と報告画面で「運転中は操作しないでください」と表示する
- 取締りの通知は「速度に注意を促す」表現にする（「取締り多発地点です。速度に注意してください」）

## 9. 開発環境（PC）

| 項目 | 推奨 |
|---|---|
| OS | Windows（今のPCのまま） |
| エディタ | Visual Studio Code |
| 実行環境 | Node.js（LTS版） |
| 言語・道具 | TypeScript、Vite、React |
| 変更履歴の管理 | Git（PC内だけで使う。GitHubへのアップロードは不要） |
| バックアップ | プロジェクトフォルダを OneDrive 等に定期的にコピー（`node_modules` は除く） |

### 9-1. PCでの動作確認の方法
- **PCのブラウザ**: Chrome の開発者ツール「Sensors」で現在地を偽装して確認
- **シミュレーションモード（開発用機能として作る）**: 記録済みの走行ルート（GPXファイル）を再生し、車に乗らずに速度・制限速度・アラートを確認できる
- **スマホで確認**: 同じWi-Fiに接続し、PCで起動した開発サーバーにスマホから接続する。位置情報にはHTTPSが必要なので、開発サーバーを自己署名証明書のHTTPSで起動する（スマホで警告が出たら許可する）
- **実車テスト**: 無料のホスティング（Cloudflare Pages 等）に置き、スマホから開く

### 9-2. フォルダ構成（案）
```
speed-alert/
├─ docs/            要件定義書など
├─ src/
│  ├─ gps/          位置・速度の取得と平滑化
│  ├─ speedlimit/   道路データ取得・道路判定・キャッシュ
│  ├─ alert/        超過判定・音声・音
│  ├─ reports/      取締り報告・表示（P2）
│  ├─ ui/           画面
│  └─ settings/     設定の保存
├─ test-routes/     シミュレーション用の走行ルート（GPX）
└─ public/          アイコン、PWA設定
```
画面とそれ以外の処理を分けておき、スマホアプリ化（Capacitor）のときに処理部分をそのまま使えるようにする。

| フェーズ | 完了条件 |

## 11. リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| 福井周辺の制限速度データが少ない | 「推定」表示ばかりになる | P1で割合を測って判断。有料地図APIへの切り替え、またはOpenStreetMapへのデータ追加 |
| 並行する道路・高架で道路を間違える | 誤った制限速度・誤アラート | 進行方向で判定、切り替えに数秒の猶予、推定・不明ではアラートを出さない初期設定 |
| 開始直後に報告が集まらない | 有料プランの価値がない | 開始時の表示基準を10件に、速報表示、P2は全員に無料試用 |
| 嘘の報告で無料期間を得る | 収益減、情報の質低下 | 他の人の報告・確認がついたものだけ特典対象、7日に1回まで |
| ブラウザ版はバックグラウンドで動かない | カーナビと同時に使えない | 利用者の声を見てP4でアプリ化 |
